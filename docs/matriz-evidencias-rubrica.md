## Cómo interpretar los estados

- **Verificado** indica que existe una comprobación ejecutada y localizable para el alcance señalado.
- **Parcial** indica que hay implementación o evidencias, pero falta una parte del criterio completo.
- **Pendiente** indica que falta la comprobación o el entregable exigido.

Una prueba local acredita su entorno y el código que ejecuta. La disponibilidad institucional, la ejecución de CI y la presentación requieren sus respectivas evidencias. El [informe de validación](informe-validacion.md) y el [índice de evidencias del 24 de noviembre](evidencias/2026-11-24/README.md) concentran los resultados de esta revisión.

## Ejecución conservada

La ejecución completa usó Python 3.13.15 y PostgreSQL 18 nativo local. JUnit registra 96 casos aprobados, cero fallos, cero errores y cero omisiones. El comando terminó con `-W error` y cero advertencias. La cobertura de líneas de `app` fue **87,38%**, con 1.440 líneas cubiertas de 1.648 ejecutables. El 88,26% indicado como antecedente queda pendiente de reproducción. Con `TEST_POSTGRES_URL` configurada hacia la base local exclusiva de pruebas, se ejecutó desde la raíz del repositorio.

```powershell
$env:E2E_STARTUP_TIMEOUT = '300'
.\.venv\Scripts\python.exe -m pytest -q -W error --cov=app --cov-report=term-missing --cov-report=xml:docs/evidencias/2026-11-24/coverage.xml --cov-fail-under=85 --junitxml=docs/evidencias/2026-11-24/junit.xml
```

El plazo de arranque E2E se amplió a 300 segundos para esta ejecución tras observar demoras de inicio en el equipo. El valor por defecto del código es de 60 segundos. E2E conserva HTTP externo, JWT y PostgreSQL reales, y se incluye la cobertura del proceso Uvicorn.
